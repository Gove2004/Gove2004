## About

I'm Gove, a student at NanChang University. I've been on GitHub since November 2023 and mostly use it as a scratchpad — I write whatever I feel like, and abandon it when it breaks.

C# is my main thing, Python second. I write HTML and TypeScript too, but only enough to get by. I wouldn't call myself good at them.

## Languages

C# is what I write most — a bit under half of my own repos. Python comes second. The rest is HTML, TypeScript, JavaScript and GDScript, picked up as I needed them.

For game stuff I write some GDScript. I played with Godot for a while.

## Projects

A few that are still worth looking at:

- **[GoveKits](https://github.com/Gove2004/GoveKits)** — C#. The one I've put the most time into, and I'm still changing it. There are [DeepWiki docs](https://deepwiki.com/Gove2004/GoveKits) for it.
- **[RVC](https://github.com/Gove2004/RVC)** — I took the original RVC and messed around with it, voice conversion. It's messy, but it runs.
- **[SpaceString](https://github.com/Gove2004/SpaceString)** — a little encryption toy that hides data in spaces, zero-width characters and that sort of thing. I thought it was neat once it worked.
- **[UnReal-Objects](https://github.com/Gove2004/UnReal-Objects)** — a small Godot game, up on [itch.io](https://gove.itch.io/unreal-objects).
- **[GamePages](https://github.com/Gove2004/GamePages)** — a site that collects game pages. [You can look here](http://gamepages.evog.top/).

There's a pile of half-finished experiments in my repos too. I won't list them all.

## What I'm into lately

Most of this past half year went into AI voice stuff. The RVC thing was me just grabbing it and changing whatever I wanted, and I've poked at some TTS and voice cloning projects as well.

Game dev never really left. I use Godot a lot, and flip through Unity once in a while.

.NET desktop tools are more or less home ground for me. Small Windows utilities are the kind of thing I keep coming back to.
